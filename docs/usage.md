# Getting started

## Environment

The project is managed with [uv](https://docs.astral.sh/uv/) and pinned to Python
3.11:

```bash
uv sync
```

With plain `venv` and `pip`, follow the steps in the repository `README.md`.

## Building these docs

The documentation dependencies live in the `docs` dependency group of
`pyproject.toml`:

```bash
uv sync --group docs
uv run sphinx-build -b html docs docs/_build/html
```

Or, from inside an activated environment:

```bash
cd docs
make html          # Linux / macOS
.\make.bat html    # Windows
```

The result is written to `docs/_build/html/index.html`. Because the API pages are
generated by `autodoc`, the environment must be able to import `functions.py` — that
is, UQpy, pyglam, scikit-learn and the remaining runtime dependencies have to be
installed.

## Typical run

Fitting a PCE surrogate at a single time step, on the durability track:

```python
import numpy as np
from UQpy.distributions import Uniform, JointIndependent

import functions as fn

joint   = JointIndependent([Uniform(20.0, 30.0), Uniform(40.0, 40.0)])
x_train = joint.rvs(nsamples=200)

result = fn.train_and_validate_pce_at_time(
    x_train=x_train,
    joint=joint,
    carb_model=carb_model,      # trained ML model with .predict and .feature_names_in_
    time_step=50.0,
    installation_year=1990,
    cement_type=3,
    exposure_conditions=2,
    output_dir='durability_final',
)
```

Splitting the same work into two stages, so the costly emulator run happens once:

```python
data = fn.generate_dataset_at_time_durability(
    x_train, x_val, carb_model, time_step=50.0, output_dir='durability_final',
)

pce = fn.train_and_validate_pce_from_dataset_durability(
    data['df_unique_train'], data['df_unique_val'], joint, time_step=50.0,
    output_dir='durability_final',
)
```

Artefacts are pickled into `output_dir` under the naming conventions documented on
each function, which is what the notebooks downstream expect.
